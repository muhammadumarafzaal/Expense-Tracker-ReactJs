# 💎 Wealth Dashboard - Advanced Expense Tracker


![Hero Image](https://images.unsplash.com/photo-1554224155-6726b3ff858f?auto=format&fit=crop&q=80&w=1200)

Wealth Dashboard is a premium, high-performance expense tracking application built with **React 19**, **Tailwind CSS v4**, and **Framer Motion**. It provides a sleek, fintech-inspired interface to help users manage their finances with precision and clarity.

# Deployment Link: expense-tracker-react-js-alpha.vercel.app

## ✨ Features

- **🚀 Real-time Analytics**: Interactive charts powered by Recharts to visualize spending patterns.
- **🎨 Premium UI/UX**: State-of-the-art design with glassmorphism, OKLCH colors, and smooth micro-animations.
- **🌓 Dynamic Theming**: Fully integrated Dark and Light modes that respect your system preferences.
- **🔍 Advanced Filtering**: Filter transactions by type, category, and time period (Monthly, Last 30 Days, etc.).
- **💾 Local Persistence**: All data is securely stored in your browser's local storage—no database required.
- **📊 Intelligence Layer**: Automatic insights that highlight your top spending categories and income momentum.
- **📥 Data Portability**: Export your entire transaction history to CSV with a single click.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Charts**: [Recharts](https://recharts.org/)
- **State Management**: React Context API & Hooks
- **Icons**: Lucide-inspired emojis & custom SVG components

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/muhammadumarafzaal/Expense-Tracker-ReactJs.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Expense-Tracker-ReactJs
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

## 📂 Project Structure

```text
src/
├── components/     # Reusable UI components (Button, Card, Modal, etc.)

├── pages/          # Main application pages (Dashboard, Auth)

```
